# 引き継ぎ初日
手順書を読んだ人が、自分で月末集計を試せる日本語の練習室です。架空の取引5件を使い、月をまたぐ返品を扱います。

**[練習室を開く](https://kotao-boop.github.io/handover-first-day/)**

## 1分で試す
初期問題で3月に0円、4月に50000円と入力してください。総額は合っていますが、返品月のヒントが返ります。3月10000円、4月40000円で再提出すると合格です。「別の金額で練習」を押すと新しい明細に切り替わります。Excelで解きたい人は明細をCSVで保存できます。

## ローカル実行
ダウンロードした index.html をブラウザで開いてください。採点は端末内で行います。Node.jsでテストを実行するには次のコマンドを使います。

    node --test grader.test.js

## Devin Botとの連携構想
この試作で実装した範囲は練習画面、明細生成、CSV保存、採点、再提出です。次の段階で担当者がSlackに手順書を渡し、出題役のDevinが練習問題を作成します。別セッションの新人役には手順書と問題だけを渡します。現在のブラウザ版は自己練習用で、採点ロジックは公開されています。正解を伏せる検証では採点をサーバー側に移す予定です。
